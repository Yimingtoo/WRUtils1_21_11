# 非破坏性测试与可写区调整（2026-10-13）

配套：[方案总纲](../redstone-unit-testing-plan.md)。此改动**取代** [Phase 2](Phase2代码实现解释.md) 的
`isolate.radius/clearArea`（清空 `origin±radius`）语义。

> **命名**：本轮同时把 JSON 键 `isolate` 改名为 `area`，记录类 `IsolationSpec` 改名为 `AreaSpec`
> （`TestDefinition` 字段同步为 `area`）。下文一律用新名。

## 一、动机

Phase 1–2 的隔离是**破坏性**的：run 开始把 `origin±radius` 整片清成空气。
但实际使用场景是**在已建好的红石机器上测试**——清空会把机器一起毁掉，显然不可用。

新目标：**测试只允许改动"输入区"**，机器本体与断言位置一律只读。

## 二、确认的四点决策（用户，2026-10-13）

1. 可写区用**新增的 `input` 矩形**定义（`{min,max}`），区域外只读。
2. **`place` 与 `use` 都受可写区限制**（点击也会改方块状态，与"写入"同级对待）。
3. 清理策略做成**可选配置**；本轮**只实现 `clear_input`**（跑前清空可写区、跑后不还原），
   `none`/`snapshot` 后续实现。
4. `forceChunks` **默认关闭**。

## 三、模型

```java
record Region(BlockPos min, BlockPos max)          // 闭区间矩形，of() 归一化，contains()/union()
enum   CleanupMode { CLEAR_INPUT, NONE, SNAPSHOT } // 仅 CLEAR_INPUT 已实现
record AreaSpec(Region input, CleanupMode cleanup,
                boolean forceChunks, boolean clearEntities,
                Map<String,Object> gameRules)
```

JSON（键名 `isolate` → `area`，内容换新）：

```json
"area": {
  "input": { "min": [100,64,200], "max": [101,64,202] },
  "cleanup": "clear_input",
  "forceChunks": false,
  "clearEntities": false,
  "gameRules": { "random_tick_speed": 0 }
}
```

- `input` 省略 = 不允许任何写入（纯观察测试）。
- **旧键 `isolate` 与旧字段 `radius`/`clearArea` 已不识别**（报错指向新字段），避免静默按新语义跑出错误结果。

## 四、校验：越界在构造时就拒绝

`TestRun` 构造函数里**先校验、后碰世界**（`validateWritable`）：
把 `setup` 脱糖成 `PlaceStep` 后，逐个检查每个 `place`/`use` 的坐标是否在 `input` 内。
越界或未定义 `input` → 抛 `IllegalArgumentException`，**在 `WorldPrep.prepare()` 之前**。

- 单跑：命令层 `catch (RuntimeException)` → 聊天里显示可读错误（Phase 2 已有）。
- 批跑：由引擎降级为一条 `ABORTED` 结果，不打断整批（Phase 3 已有）。

之所以选"构造时校验"而不是"执行时报错"：后者会**改了一半才发现**，且 `clear_input` 可能已经清过区域。

## 五、范围计算：`chunkRegion`

`forceChunks`/`clearEntities` 的作用范围 = **可写区 ∪ 全部步骤坐标**（含 `assert`——
机器要 tick 才读得准，断言目标所在区块也得加载）。由 `TestRun.chunkRegion(...)` 算出后传给 `WorldPrep`。
`origin` 不再是区域基准，仅作报告用的参考点。

## 六、清理策略

| mode | 行为 | 状态 |
|---|---|---|
| `clear_input` | 跑前把可写区清成空气（`NOTIFY_ALL`，保留红石更新语义）、跑后不还原 | ✅ 已实现 |
| `none` | 完全不碰方块 | 未实现（选用即报错） |
| `snapshot` | 跑前快照可写区方块+方块实体 NBT，结束时写回 | 未实现（选用即报错） |

`restore()` 的职责不变且仍幂等：只还原**全局量**（gamerule、强制区块）。

## 八、关键不变量（追加到 Phase 3 的 14 条之后）

15. **写操作的唯一合法范围是 `area.input`**；`place`/`use` 越界在 `TestRun` 构造时即被拒绝，
    且拒绝发生在 `WorldPrep.prepare()` 之前（不碰世界）。
16. **`assert` 不受可写区限制**（只读），但同样计入 `chunkRegion` 以参与强制区块。
17. **`forceChunks`/`clearEntities` 默认 `false`**；需要时按测试显式开启。
18. **未实现的 cleanup 模式必须报错**，不能静默当作 `none` 处理。
